# Mayank Shanbhag — Portfolio

My personal portfolio: a backend developer's corner of the internet, with interactive project blocks, a terminal you can type into, and a particle background that reacts to your mouse.

🌐 **Live site:** [Mayank Shanbhag Portfolio](https://lynx-mayank.github.io/portfolio/)

![Portfolio screenshot](./screenshot.png)

## What's inside

- **Hero:** typing effect, animated name and a scrolling tech-stack strip
- **About:** tabbed intro plus a working terminal (try `help`, `projects`, `theme pink`, `matrix`)
- **Mini projects:** small tools, each with a GitHub link and a live site
- **Major projects:** larger builds with animated banners
- **Domains:** Backend, REST APIs, AWS, GCP, Database (SQL) and DevOps, with the skills I use in each

## Tech

Plain HTML, CSS and vanilla JavaScript in a single `index.html`. No framework, no build step, no dependencies besides Google Fonts.

## Run locally

```bash
git clone https://github.com/Lynx-Mayank/<repo-name>.git
cd <repo-name>
# just open index.html in your browser, or serve it:
python -m http.server 8000
```

## Customise

All content (projects, skills, links) lives in the config block at the top of the `<script>` in `index.html`. To add a project, add one line to the `MINI` or `BIG` list.
